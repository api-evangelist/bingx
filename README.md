BingX is a cryptocurrency exchange offering spot, perpetual futures (USDT-M and Coin-M), copy trading and wealth products. It exposes a public REST trading API at open-api.bingx.com and WebSocket market data streams, authenticated with an API key header and HMAC SHA256 request signatures.

**Areas:** Company · Cryptocurrency · Exchange · Trading · Financial Services

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for BingX: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
